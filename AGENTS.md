# Learner

PWA, що перетворює папку Google Drive на відеокурс із відстеженням прогресу. Без бекенду: відео грає через Service Worker, що проксує Drive API; прогрес лежить в IndexedDB і синхронізується між пристроями через приховану `appDataFolder` у Drive самого користувача. Деплой — GitHub Pages: https://student-magura.github.io/learner/

## Незмінні правила

- **Прогрес — єдині дані, яких нізвідки не відновити.** Записи прогресу лише додаються й оновлюються, ніколи не видаляються — навіть разом із курсом чи відео, що зникло з Drive.
- Прогрес ключований **Drive `fileId`**, тривалість — **у секундах** усюди. Мілісекунди Drive переводяться на межі `src/drive/api.ts`.
- Кожен виклик Drive API до папок і файлів несе `supportsAllDrives=true` і `includeItemsFromAllDrives=true` — інакше спільні папки мовчки повертають порожнечу.
- Базовий шлях `/learner/` задано одним константом у `vite.config.ts`; у коді шляхи будуються від `import.meta.env.BASE_URL`.

## Готово — це

`npm test` і `npm run build` обидва зелені (збірка включає `tsc --noEmit`). Для змін відтворення відео цього **замало**: юніт-тести не бачать CORS, життєвого циклу воркера й медіа-движка — перевіряйте в справжньому браузері (рецепт у `media-playback.md`).

Пуш у `main` одразу деплоїть на Pages через GitHub Actions.

## Джерела правди

Код > `docs/memory-bank/` > спека `docs/superpowers/specs/` > план `docs/superpowers/plans/`. План — історія: блоки коду з позначкою «> **Увага:**» замінені реалізацією, яка свідомо від них відходить.

## Memory bank — `docs/memory-bank/`

- `status.md` — **на старті будь-якої задачі**: поточний стан, неперевірене, відомі прогалини.
- `media-playback.md` — плеєр, Service Worker, маршрут `/media/`, запасний плеєр Drive, «відео не грає».
- `auth.md` — вхід, токени, GIS, обробка 401.
- `progress-sync.md` — прогрес, IndexedDB, синхронізація з `appDataFolder`, злиття.
- `courses.md` — сканування папки Drive, дерево курсу, додавання курсу.
- `testing.md` — написання й лагодження тестів.
