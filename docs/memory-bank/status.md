# Стан проєкту

Оновлено: 2026-10-10. Цей файл старіє найшвидше — оновлюйте його, коли закриваєте пункт або знаходите новий.

## Що є

Зібрано за планом із 17 задач (спека й план у `docs/superpowers/`), кожна задача пройшла ревʼю, потім фінальне ревʼю всієї гілки. Після деплою — три раунди налагодження відтворення на справжньому браузері (див. `media-playback.md`). Потім інший сеанс зробив редизайн інтерфейсу: дві теми на CSS-змінних, програма курсу одним списком поруч із відео.

## Неперевірене — почніть звідси, якщо задача торкається відео

1. **Синтез `Content-Range` (коміт `4dfe6c9`) задеплоєний, але не підтверджений наскрізно.** Перевірку в браузері перервало перезавантаження сторінки, яке розлогінює (див. `auth.md`). До правки було підтверджено спостереженням: воркер віддавав `206` без `Content-Range`, `<video>` падав з `MediaError` 4. Після правки треба побачити `206` *з* `Content-Range` і `loadedmetadata` — рецепт у `media-playback.md`.
   **`CLAIM` після жорсткого перезавантаження** (див. `media-playback.md`) підтверджено лише юніт-тестами: що Chrome віддає воркеру сторінку після Shift+Reload через `clients.claim()`, у справжньому браузері ще не перевіряли.
2. **iOS Safari не перевірявся ніколи.** Спайк так і не проведено: `spike.html`, `public/sw-spike.js` і порожній `docs/superpowers/plans/2026-09-20-spike-result.md` чекають у репо. Видаліть їх разом із записом у `tailwind.config.js` після того, як спайк буде проведено.
3. **Критерії приймання 1–6** у `docs/superpowers/plans/2026-09-20-acceptance.md` порожні — потрібні справжній вхід і два пристрої.
4. **Хвиля виправлень після фінального ревʼю** (коміти `f7a6bc3..e97ce43`) не мала незалежного ре-ревʼю: агента обірвав ліміт до звіту.

## Відомі прогалини продукту

- **Кожне перезавантаження сторінки вимагає входу.** Токен живе лише в памʼяті сторінки, тихого входу на старті немає.
- **Бібліотека курсів не синхронізується.** Синхронізується лише прогрес; на новому пристрої курс треба додати знову, і тоді прогрес підтягнеться.
- Посилання формату `drive.google.com/open?id=…` не приймаються — лише `/folders/{id}`.
- Немає кнопки виходу (`tokenClient.signOut` ні до чого не підʼєднано).
