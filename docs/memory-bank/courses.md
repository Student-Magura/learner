# Курси

Два розділи бібліотеки: **каталог** (`source: 'catalog'`) — спільний для всіх, зʼявляється сам і прибрати його не можна; **власні курси** (поле `source` відсутнє або `'own'`) — додаються за посиланням.

## Каталог — `syncCatalog` у `src/store/useStore.ts`

- Папка каталогу — `VITE_CATALOG_FOLDER_ID` (збірка, як і Client ID; у CI — variable репозиторію). Кожна її підпапка — курс. Не задано — каталогу немає.
- Запускається з `init` **у фоні**: `ready` не чекає на нього, а `catalogSyncing` вмикає індикатор «Оновлюємо каталог…» у бібліотеці.
- Один `listFolder` каталогу: нові підпапки скануються паралельно, зниклі курси каталогу прибираються (прогрес лишається). Уже відомі курси **не пересканьовуються** — це десятки запитів на старт; оновлення — кнопкою rescan на сторінці курсу.
- Збій скану одного курсу ковтається: курс спробує знову на наступному старті. Офлайн — лишаються закешовані.
- Власний курс з id підпапки каталогу переходить у каталог без пересканування й без дубля. `addCourse` курсу, що вже в каталозі, відмовляє; `rescanCourse` зберігає `source`.
- Одночасні виклики злипаються в один прохід.

## Додавання власного курсу

Користувач вставляє посилання на папку → `parseFolderId` (`src/drive/parseFolderUrl.ts`) → `scanCourse` → IndexedDB.

- `parseFolderId` вимагає ID від 20 символів — справжні ID Drive довгі, і ця перевірка перетворює помилку у вставці на зрозуміле повідомлення. Фікстури тестів мусять мати реалістичні ID.
- Помилки Drive `403`/`404` стор перекладає людською мовою про посилання й доступ.

## Сканер — `src/drive/courseScanner.ts`

- Рекурсивний, без припущення про глибину: курс-приклад має два рівні папок, інший може мати один чи три.
- Уроки — лише `mimeType` `video/*`. Відкидаються `.DS_Store`, файли з крапкою на початку, `trashed`.
- Папка без жодного відео **в усьому піддереві** зникає цілком, а не лишається порожнім розділом.
- **Порядок масиву `children` і є порядком курсу** — сканер сортує один раз, далі ніхто не пересортовує. Natural sort: `Intl.Collator` з `numeric: true`, щоб `2` йшло перед `10`, а `01` дорівнювало `1`. `sensitivity` навмисно не задано: `'base'` робила назви, що відрізняються лише регістром, «рівними», і порядок таких розділів ставав випадковим.
- `MAX_DEPTH` обриває цикли через ярлики Drive.

## Drive API — `src/drive/api.ts`

- Обидва параметри Shared Drives — на кожному виклику до папок і файлів, на кожній сторінці пагінації. Без них спільна папка повертає **порожній список, а не помилку**, і курс виглядає порожнім. Виклики до `appDataFolder` навмисно без них: це приватний простір, не Shared Drive.
- `durationMillis` → секунди саме тут і більше ніде.
- Backoff з jitter на `429`/`5xx` і на `403` *лише* з причинами rate limit. `403` за правами падає одразу.

## Зникле відео

Пропадає з дерева після повторного сканування; запис прогресу лишається. Сторінка уроку за старим посиланням показує «урок не знайдено».
